# 02 协议方法表（骨架）

状态：待填。负责人：待定。冻结后作为 C 库与 `sdk/server` 的接缝。

## 一、传输与分帧

待填：stdio、逐行 JSON-RPC、UTF-8、单行上限、超长行的处理方式、日志只能写 stderr。

## 二、方法表

| 方法 | 方向 | 入参 | 出参 | 是否立即返回 | 备注 |
| --- | --- | --- | --- | --- | --- |
| `initialize` | 客户端 → 运行时 | 工作目录、provider、模型、可选推理强度 | 服务标识与版本 | 是 | 官方已有 |
| `session/prompt` | 客户端 → 运行时 | 会话 id、内容块 | 消息 id | 是 | 官方已有，未知会话懒创建 |
| `session/cancel` | 客户端 → 运行时 | 会话 id | 空 | 是 | 新增，映射内核 `Agent.cancel` |
| `rsi.set` | 客户端 → 运行时 | 开关布尔值 | 切换后的状态 | 是 | 新增，下一个 turn 生效 |
| `rsi.get` | 客户端 → 运行时 | 无 | 当前状态与来源 | 是 | 新增 |
| `trace.export` | 客户端 → 运行时 | 会话 id、目标路径 | 导出结果 | 是 | 新增，二期可降级为导出日志 |
| `shutdown` | 客户端 → 运行时 | 无 | 空 | 否 | 官方已有，退出进程 |

待补：每个方法的完整字段表、必填与可选项、取值范围、错误码。

## 三、通知表

| 通知 | 方向 | 载荷 | 说明 |
| --- | --- | --- | --- |
| `session.event` | 运行时 → 客户端 | 会话 id、事件信封 | 官方已有，全量会话事件 |
| `session.status` | 运行时 → 客户端 | 会话 id、idle/running | 官方已有 |
| `assistant.delta` | 运行时 → 客户端 | 会话 id、序号、文本片段 | 新增，可合并 |
| `rsi.state` | 运行时 → 客户端 | enabled、source | 新增 |
| `subagent.started` / `subagent.finished` | 运行时 → 客户端 | 父子会话 id、状态 | 官方已有，按需透传 |

待补：每种通知在什么时点发出、与 `session.event` 的先后关系。
