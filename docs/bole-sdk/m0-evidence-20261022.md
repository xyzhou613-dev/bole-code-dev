# M0 / C2 证据（2026-10-22）

范围：控制台示例 + 真实 `--profile sdk` 运行时 + 玩具 MCP + mock 模型，跑通一次
「模型 → MCP 工具调用 → 结果 → 终态」。

## 环境

- 开发机：macOS（POSIX 平台层；Windows/MSVC 另验）
- 运行时：锁定的 `0.1.7-alpha.2` 运行时树
- 模型：`runtime/dev/mock-model.mjs`，脚本化工具调用 `mcp__toy__add`
- 工具：`examples/toy-mcp/server.mjs`
- 桥接插件与经验包：`runtime/dev` 构建后安装
- C SDK：`develop` 分支，`native/` 当前实现

## 命令

```bash
cmake -S examples/console-c -B <build-dir> -DCMAKE_BUILD_TYPE=Release
cmake --build <build-dir> -j4

BOLE_DEV_RUNTIME=<runtime> node examples/console-c/smoke.mjs \
  <build-dir>/bole_console
```

`smoke.mjs` 启动 mock 模型，装配临时运行时（含玩具 MCP 行），执行
`bole_console <runtime> <home> "用玩具工具计算 1+2"`，收集 stdout/stderr 和耗时。

- 本证据使用 mock 模型和玩具 MCP，不依赖外网或真实网关。

  B3/B8 在目标环境验证。
